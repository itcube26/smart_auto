# 🚗 Smart Auto
### Автомобиль будущего · Инженеры транспорта

**Smart Auto** — концепт автомобиля будущего с уникальным авторским дизайном. Проект включает 3D-моделирование, детали для 3D-печати, собственные логотипы и коллекцию автомобильных наклеек.

## 💡 О проекте

**Smart Auto** — это объединение инженерии, 3D-моделирования и творческого автомобильного дизайна.

От цифровой модели до готовой детали, от идеи логотипа до оформления кузова — каждый элемент создаёт уникальный облик автомобиля будущего.

**Направление:** Инженеры транспорта  
**Проект:** Smart Auto 🚗
