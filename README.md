# 🚗 Smart Auto — Автомобиль будущего

Проект направления **«Инженеры транспорта»**: концепт автомобиля будущего с полностью кастомным дизайном — 3D-модели для печати, авторские наклейки и логотипы.

## 📌 Постер проекта

Главное визуальное представление проекта — **постер А3** (`Презентация/Постер/A3.png`). Файл ещё не закоммичен в репозиторий; ниже временно показан лист А4, который уже в git:

![Постер (лист А4)](Наклейки/A4.png)

```
.
├── README.md
├── STL
│   ├── Корпус          — лицевая часть (.stl/.3mf), мотор+колёса+вентилятор (.stl)

│   ├── Акула           — серия наклеек «Акула»

│   ├── Логотип         — эскизы, SolidCraft/DXF, версии и рендеры
│   └── Презентация     — слайды 1–6, лист A4, figcraft-исходники
```
