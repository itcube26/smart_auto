# Smart Auto 

Проект умного автомобиля с кастомным 3D-корпусом и авторским дизайном наклеек.

## 📌 Постер проекта (А4)

Главный постер проекта формата А4 — общий лист с дизайном автомобиля и наклеек:

![Постер А4](Наклейки/Презентация/A4.png)

*Файл: [`Наклейки/Презентация/A4.png`](Наклейки/Презентация/A4.png)*

##  Структура проекта

```
smart_auto/
├── STL/
│   ├── Корпус/          # 3D-модели корпуса (.stl, .3mf)
│   └── Декор/           # Спойлеры и руль (.stl + превью .png)
├── Наклейки/
│   ├── Акула/           # Наклейки с акулой
│   ├── Босудзоку стиль/ # Наклейки в японском стиле босодзоку
│   ├── Логотип/         # Логотипы проекта
│   ├── Презентация/     # Презентационные материалы и постер A4.png
│   └── A4.png           # Копия постера А4
└── README.md
```

| Классный спойлер | Крутой спойлер | Руль |

| ![Классный спойлер](STL/декор/классный%20спойлер.png) | ![Крутой спойлер](STL/декор/крутой%20спойлер%20%281%29.png) | ![Руль](STL/декор/руль%20классный%20%282%29.png) |
| [`классный спойлер.stl`](STL/декор/классный%20спойлер.stl) | [`крутой спойлер (1).stl`](STL/декор/крутой%20спойлер%20%281%29.stl) | [`руль классный (2).stl`](STL/декор/руль%20классный%20%282%29.stl) |
